Trois ans à construire des applications web et mobiles, et une année au Japon.

Par Camille Lupo
Angular · React · Java Spring Boot · Python · React Native

Développeur full-stack, trois ans d'expérience en Angular, React, Java Spring Boot et Python, avec de l'intégration IA/LLM et de l'architecture microservices.

Après une année au Japon (2023-2025) passée à apprendre la langue, de retour en France, à Rouen. Cette année-là a laissé deux choses : un japonais de niveau intermédiaire, et un projet d'application pour apprendre les kanjis.

Côté back, l'essentiel du travail tourne autour d'API REST — Java Spring Boot et MongoDB chez TROP-PLUS, Python avec Sanic et FastAPI depuis. Côté front, Angular et React en mission, Vue.js sur les back-offices.

Le mobile est venu par le terrain : trois applications React Native livrées et mises en production sur des événements réels, où une lecture de QR code qui échoue bloque une file d'attente.

Chez REDLAB, le sujet a été l'intégration LLM : configuration de prompts multi-fournisseurs, paramètres dynamiques, gestion conditionnelle selon les capacités de chaque modèle.

Le reste — Docker, CI/CD, tests de charge — est l'outillage qui permet de livrer sans réveiller personne la nuit.
